# TI4 Host-Leitfaden

Interaktive Host-Übersicht für **Twilight Imperium 4 mit Prophecy of Kings**: Rundenablauf, Checklisten für jede Phase, taktische Aktion, Raum- und Bodenkampf, Timing-Regeln für Aktionskarten, Handel, Limits, PoK-Neuerungen und Aufbau.

## Nutzung

`index.html` im Browser öffnen. Es gibt keine Abhängigkeiten außer Google Fonts.
Abgehakte Punkte, aktuelle Runde und der Custodians-Status werden im `localStorage` des Browsers gespeichert.

## Quellen

Kurzfassung auf Basis der Living Rules Reference (TI4 + Prophecy of Kings). Bei Abweichungen gelten Kartentext und Rules Reference.
