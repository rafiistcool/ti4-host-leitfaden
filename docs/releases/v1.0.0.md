Erste Version des TI4 Host-Leitfadens mit eigenem Hub für die Spielrunde.

## Leitfaden

- Schritt-für-Schritt-Ablauf einer Partie Twilight Imperium IV (Prophezeiung der Könige) für den Spielleiter
- Kampfablauf, Regelreferenz A–Z, Themen, Suche
- Aufbau mit Kartengenerator, Kompendium mit Fraktionen, Technologien, Karten und Originalmaterial
- Installierbar als App (PWA), funktioniert offline

## Hub für die Spielrunde

- Countdown zur nächsten Session, Teilnehmer und Fraktionswahl zum Antippen
- Sessions planen und nachtragen, Historie mit Siegpunkten, Platzierungen und Sieger
- Spieler- und Fraktionsstatistiken
- Gleichzeitiges Bearbeiten wird erkannt, statt still zu überschreiben
- Ohne Server (GitHub Pages) speichert der Hub lokal im Browser

## Accounts und Sicherheit

- Anschauen für alle, Ändern nur mit Login
- Registrieren mit Gruppencode, den der Admin öffnet und schließt; Einladungslinks für Nachzügler und vergessene Passwörter
- Erster Admin über einen Einrichtungscode aus dem Server-Log
- Profil: Namen und Passwort ändern, überall abmelden, Account löschen
- Admin-Bereich: Registrierung, Accounts, Rollen, Einladungen
- Verlauf aller Änderungen, der Admin kann sie rückgängig machen
- Tägliche Sicherung der Datenbank, Bremse gegen Passwort-Raten

## Installation

```bash
docker compose pull && docker compose up -d
docker logs ti4-hub-api 2>&1 | grep Code   # Einrichtungscode für den ersten Admin
```

Images: `ghcr.io/rafiistcool/ti4-host-leitfaden:1.0.0` (Seite) und `ghcr.io/rafiistcool/ti4-host-leitfaden-api:1.0.0` (Hub-API), jeweils auch als `latest`. Details im README unter „Schnellstart“.
